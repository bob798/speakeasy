# ADR-002：grammar_cards 使用 pending/active 两步状态而非直接 active

**状态**：已采纳
**日期**：2025-03-01
**决策者**：Human + Claude

## 背景

用户第一次犯某个语法错误时，需要决定是否立即创建 FSRS 记忆卡片。

## 决策

引入 pending 状态：第一次出现 → pending，第二次出现 → active（创建 FSRS Card）。

## 原因

- 用户偶尔说错一次不代表是需要重点记忆的错误
- frequency >= 2 作为门槛，过滤掉一次性偶发错误
- 避免 FSRS 卡片过多导致复习负担过重
- 无需引入 LanguageTool 等外部依赖，纯 LLM 方案

## 后果

- 正面：大幅减少误判和无效卡片
- 负面：用户第一次犯错不会被追踪（可接受，第二次才是真正的模式）

## 被此决策取代

无
