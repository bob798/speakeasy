# ADR-004：Alex 采用"永不显性纠错"原则

**状态**：已采纳
**日期**：2025-03-01
**决策者**：Human（核心产品原则）

## 背景

需要决定 AI 角色 Alex 在检测到用户英语错误时的处理方式。

## 决策

Alex 永远不以任何形式指出用户的错误，只在自己的回复中自然使用正确表达。

## 原因

- 显性纠错破坏对话自然感，用户会有"被老师批评"的心理压力
- 用户使用 Speakeasy 的动机是"练习"而非"被纠正"
- 自然示范的习得效果经研究证明不亚于显性纠错

## 后果

- 正面：对话体验更自然，用户留存率更高
- 负面：用户可能感知不到错误被处理（接受，这是设计意图）
- 实现：SYSTEM_PROMPT 包含绝对禁令，见 BUG_LOG BUG-001

## 验证

见 ALEX_BEHAVIOR_TEST_STANDARD.md，D1 维度（禁止行为）全部测试用例。
