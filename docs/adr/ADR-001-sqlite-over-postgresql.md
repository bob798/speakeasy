# ADR-001：使用 SQLite 而非 PostgreSQL

**状态**：已采纳
**日期**：2025-03-01
**决策者**：Human

## 背景

Speakeasy V0.x 阶段为单用户本地部署，需要选择数据库方案。

## 决策

使用 SQLite。

## 原因

- 零配置，无需独立数据库进程，降低部署复杂度
- 数据文件可直接复制备份
- V0.x 阶段单用户 QPS < 10，SQLite 完全满足需求
- 团队规模：Human + AI，无需多用户并发写入

## 后果

- 正面：开发启动成本极低，无需 Docker 或数据库服务
- 负面：不支持高并发写入（当前阶段无影响）
- 迁移路径：V1.0 多用户版本时迁移至 PostgreSQL，迁移成本已在路线图中评估
